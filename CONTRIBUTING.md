# Contributing

Thanks for helping! Is repo ko beginners ke liye aur behtar banane mein madad karo.

## Kaise help kar sakte ho
- 🐛 **Error report:** Issue kholo. Ye batao: kaunsa step, kya dikha, screenshot, Elementor/WordPress version.
- 🌍 **Translation:** Docs ko English (ya aur languages) mein translate karo.
- 📸 **Screenshots:** `assets/screenshots/` mein add karo (naming: `04-hero-result.png`).
- 🧩 **Naye sections:** Inner pages, hamburger menu, pricing table, FAQ accordion.

## Guidelines
- Steps chhote aur click-by-click rakho ("X menu → Y button").
- Har step ke saath **expected result** likho.
- Error add karo to format: **Symptom → Wajah → Fix**.
- CSS ko `css/nextin.css` mein ek hi jagah rakho. Duplicate blocks nahi.
- Fake stats/testimonials add mat karo.

## Pull request
1. Fork → branch (`fix/bento-mobile`)
2. Change + docs update
3. PR mein before/after screenshot
